# GitHub Pages 个人博客 — Apple 风格

## 概述

创建一个纯静态 GitHub Pages 个人博客，采用 Apple 设计语言（毛玻璃材质、弹簧动画、系统字体），支持 Markdown 文章渲染（图片、表格、代码高亮），响应式侧栏导航，深色/浅色主题自动切换。

## 文件结构

```
Original-YuanZiE.github.io/
├── index.html                 # SPA 入口（唯一的 HTML 文件）
├── Posts/                     # 文章目录
│   ├── index.json             # 文章索引（手动维护）
│   └── 示例文章/
│       ├── main.md            # 文章内容（Markdown + frontmatter）
│       └── Assets/            # 文章图片资源
├── Assets/                    # 全站资源
│   ├── favicon.svg
│   └── avatar.png             # 占位头像
├── Style/                     # CSS 模块
│   ├── variables.css          # 主题变量（颜色、字体、间距）
│   ├── base.css               # 重置、排版、全局样式
│   ├── layout.css             # 侧栏 + 主内容区网格布局
│   ├── components.css         # 侧栏导航、文章列表、主题切换
│   ├── article.css            # Markdown 内容渲染样式
│   └── responsive.css         # 响应式断点、减弱动态效果
├── Script/                    # JS 模块
│   ├── app.js                 # 入口，初始化路由
│   ├── router.js              # Hash 路由
│   ├── theme.js               # 深色/浅色主题管理
│   ├── sidebar.js             # 侧栏折叠/展开（弹簧动画）
│   ├── markdown.js            # Markdown 渲染（marked.js + highlight.js）
│   └── articles.js            # 文章索引加载
└── OldSite/                   # （不动）
└── SubSite/                   # （不动）
```

## 架构设计

### 路由：Hash SPA

| 路由 | 页面 |
|------|------|
| `#/` | 首页（个人简介 + 最新文章） |
| `#/articles` | 全部文章列表 |
| `#/articles/:id` | 单篇文章（渲染 main.md） |
| `#/about` | 关于页面 |

使用 `hashchange` 事件监听，无需服务器配置。

### 文章发现：JSON 索引

`Posts/index.json` 是文章目录的唯一数据源：

```json
[
  {
    "id": "2502106A",
    "title": "版本发布",
    "date": "2025-02-06",
    "tags": ["系统", "发布"],
    "summary": "基于 Windows 11 24H2 的...",
    "cover": "Posts/2502106A/Assets/cover.png"
  }
]
```

### Markdown 渲染流程

```
Posts/:id/main.md
  ↓ fetch()
原始 Markdown（含 YAML frontmatter）
  ↓ 手动解析 frontmatter
{ meta: {title, date, tags, cover}, body: "markdown" }
  ↓ marked.parse(body) + highlight.js
HTML → 注入 #app
```

### 文章格式：main.md

```markdown
---
title: "文章标题"
date: "2025-02-06"
tags: ["标签1", "标签2"]
summary: "简短描述"
cover: "Assets/cover.png"
---

正文内容...
![图片](Assets/screenshot.png)
```

| 字段 | 必填 | 说明 |
|------|------|------|
| title | 是 | 文章标题 |
| date | 是 | 发布日期 (YYYY-MM-DD) |
| tags | 否 | 标签数组 |
| summary | 否 | 列表页摘要 |
| cover | 否 | 封面图（相对路径） |

## Apple 设计实现

### 毛玻璃材质（侧栏）

```css
.sidebar {
  background: var(--color-glass);
  backdrop-filter: blur(20px) saturate(180%);
  border-right: 1px solid var(--color-glass-border);
}
```

### 主题变量

```css
:root {
  --color-bg: #f5f5f7;
  --color-ink: #1d1d1f;
  --color-accent: #0071e3;
  --color-glass: rgba(255,255,255,0.72);
  /* ... */
}
[data-theme="dark"] {
  --color-bg: #000000;
  --color-ink: #f5f5f7;
  --color-accent: #0a84ff;
  --color-glass: rgba(29,29,31,0.72);
  /* ... */
}
```

### 排版

- 字体：`system-ui, -apple-system, 'PingFang SC', 'Noto Sans SC', sans-serif`
- 大标题：负字间距 `-0.02em`，行高 `1.1`
- 正文：`16px/1.75`，舒适的中文阅读体验
- 代码：`'SF Mono', 'Cascadia Code', Consolas, monospace`

### 动画策略

| 交互 | 类型 | 参数 |
|------|------|------|
| 侧栏展开/收起 | 弹簧 | `damping: 1.0, response: 0.4` |
| 页面切换 | 淡入淡出 | `opacity 0→1`, 200ms |
| 文章列表悬停 | CSS | `transform 100ms` |
| 主题切换按钮 | 弹簧 | `damping: 0.8, response: 0.3` |
| 按钮按下 | CSS | `scale(0.97)`, 100ms |
| 减弱动态效果 | `@media (prefers-reduced-motion)` | 仅淡入淡出 |

### 响应式布局

- `≥1024px`：侧栏展开（280px），固定左侧
- `<1024px`：侧栏收起，汉堡按钮浮于左上角，点击展开为覆盖层

## 实施顺序

1. `index.html` — SPA 外壳 + CDN 链接 + 侧栏骨架
2. `Style/variables.css` — CSS 主题变量
3. `Style/base.css` — 重置、排版
4. `Style/layout.css` — 侧栏 + 主内容区网格
5. `Style/components.css` — 侧栏导航、文章列表、主题切换按钮
6. `Style/article.css` — Markdown 渲染样式
7. `Style/responsive.css` — 响应式断点
8. `Script/theme.js` — 主题管理（auto/light/dark）
9. `Script/router.js` — Hash 路由
10. `Script/articles.js` — 文章索引加载
11. `Script/markdown.js` — Frontmatter 解析 + marked.js 配置
12. `Script/sidebar.js` — 侧栏弹簧动画
13. `Script/app.js` — 组装所有模块
14. **示例文章** — 创建 `Posts/hello-world/main.md`，内容涵盖标题、段落、图片引用、表格、代码块、列表等常见 Markdown 元素，作为渲染效果的完整演示
15. `Posts/index.json` — 文章索引，包含示例文章的条目
16. `Assets/` — favicon.svg + 占位头像

## 验证方式

1. 本地用 `npx serve .` 或 Live Server 打开 `index.html`
2. 检查：
   - 侧栏在宽屏展开、手机收起
   - 深色/浅色主题自动切换 + 手动切换
   - 文章列表正确加载
   - 点击文章进入详情页，Markdown 正确渲染（图片、表格、代码高亮）
   - 弹簧动画流畅，减弱动态效果模式下无动画
   - 毛玻璃材质效果正常显示
