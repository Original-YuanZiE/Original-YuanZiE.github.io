# 个人网站 Material You 重构计划

## 一、现状分析

**当前站点**：纯静态 HTML + MDUI 2.0.6（Material Design 3 Web Components），无构建工具。
- 3 个页面：`index.html`（主页）、`article.html`（文章列表）、`Articles/2502106A/index.html`（文章详情）
- 大量内联样式，无共享 CSS
- 添加文章需手动创建文件夹 + 编辑 article.html
- 无管理员功能

**约束条件**：
- GitHub Pages 静态托管，无服务端
- 不得修改或查看 `SubSite/` 文件夹
- 继续使用 MDUI 2.x（已是 Material You 实现）

---

## 二、重构方案

### 2.1 整体架构

保持纯静态 HTML 架构，引入一个轻量级的客户端管理面板（admin.html），通过 GitHub API 实现文章发布。

**页面结构**：
```
index.html          — 首页（全新 Material You 布局）
article.html        — 文章列表页（动态加载）
article.html?id=xxx — 文章详情页（共用同一文件，JS 路由）
admin.html          — 管理员登录 + 文章发布面板
Articles/           — 文章数据（JSON + Markdown 或 HTML）
Files/              — 静态资源
Theme/              — MDUI + 自定义样式
```

### 2.2 首页重设计（index.html）

**Material You 风格要点**：
- 使用 MDUI 的 Dynamic Color（动态取色）或精心挑选的调色板
- Hero section：大标题 + 简介 + 头像，背景使用柔和渐变
- 卡片网格展示最新文章（从 `Articles/manifest.json` 动态加载）
- 底部 Footer 含社交链接（Bilibili 等）
- 响应式布局：桌面端多列，移动端单列
- 保留自动亮/暗主题切换

**视觉目标**：大气简洁、留白充足、圆角卡片、柔和阴影

### 2.3 文章系统重构

**数据格式**：每篇文章存为 `Articles/<id>/index.html`（保持兼容），新增 `Articles/manifest.json` 作为文章索引：

```json
[
  {
    "id": "2502106A",
    "title": "版本发布",
    "date": "2025-02-06",
    "category": "系统与应用",
    "author": "元子鹅",
    "cover": "Articles/2502106A/Cover.png",
    "excerpt": "基于 Windows 11 24H2 的 Original YuanZiEOS 2 与 GeminiCoreX 正式发布..."
  }
]
```

**文章列表页**（article.html）：
- 从 manifest.json 动态加载文章卡片
- 支持分类筛选（使用 MDUI Segmented Button）
- 卡片含封面图、标题、日期、摘要

**文章详情**：
- 保持独立 `Articles/<id>/index.html` 结构
- 统一使用 MDUI 组件排版，移除内联样式
- 添加返回按钮、面包屑导航

### 2.4 管理员登录 + 文章发布（admin.html）

**认证方案**：GitHub Personal Access Token (PAT)
- 管理员在登录页输入 GitHub PAT
- Token 存储在 localStorage（仅当前浏览器）
- 通过 GitHub API 验证 Token 有效性

**发布流程**：
1. 管理员登录后进入发布面板
2. 填写文章元数据（标题、分类、日期）
3. 编辑文章内容（使用简单的 textarea 或集成轻量 Markdown 编辑器）
4. 上传封面图片
5. 点击发布 → 通过 GitHub API 创建/更新文件到仓库
6. 自动更新 manifest.json

**技术实现**：
- 使用 GitHub REST API（`api.github.com`）
- 前端纯 JS，无需构建
- 使用 `fetch` + `btoa` 进行 Base64 编码提交

### 2.5 共享样式系统

创建 `Theme/custom.css`：
- CSS 变量定义主题色（Material You 调色板）
- 响应式断点（mobile: <768px, tablet: 768-1024px, desktop: >1024px）
- 通用排版样式
- 卡片网格布局
- 页面过渡动画

### 2.6 共享组件（公共 JS）

创建 `Theme/common.js`：
- 导航栏组件（避免每个页面重复 HTML）
- 页脚组件
- 主题切换逻辑
- manifest.json 加载器

## 五、验证方案

1. **本地预览**：使用 `python -m http.server` 或 VS Code Live Server 本地运行
2. **功能验证**：
   - 首页加载正常，文章预览显示
   - 文章列表动态加载，分类筛选可用
   - 文章详情页排版美观
   - 管理员登录成功（输入有效 PAT）
   - 文章发布流程完整（创建 → 提交 → manifest 更新）
3. **视觉验证**：
   - 亮/暗主题切换正常
   - 移动端响应式布局正确
   - Material You 风格一致性
4. **安全验证**：
   - SubSite 文件夹未被修改
   - GitHub Token 仅存于 localStorage
